# Adventure Works Sales Dashboard

## Project Overview
This project analyzes Adventure Works sales data using Power BI to identify sales trends, product performance, customer behavior, and regional sales performance.

## Tools & Technologies
- **Power BI** – Interactive dashboard and data visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – Measures and business calculations
- **Excel** – Data inspection and validation

## Business Objectives
- Analyze overall sales and profit performance.
- Identify top-performing products and product categories.
- Track monthly and yearly sales trends.
- Understand customer purchasing behavior.
- Compare sales performance across regions.

## Key Performance Indicators (KPIs)
- Total Sales
- Total Profit
- Total Orders
- Profit Margin %
- Year-over-Year Sales Growth

## Project Workflow
1. Import the Adventure Works dataset.
2. Clean and transform the data using Power Query.
3. Build relationships between data tables.
4. Create DAX measures for key metrics.
5. Design an interactive Power BI dashboard.
6. Document insights and business recommendations.
